Cloudio (Smart Home Server & AI Lab)

Servidor pessoal rodando em Raspberry Pi 4 (OpenMediaVault + Tailscale), combinando armazenamento centralizado e automação inteligente:

  • AdBlocking & Segurança: Filtro de anúncios e rastreadores em nível de rede via DNS.
  • Smart NAS: Armazenamento redundante para backups automatizados e gestão de arquivos.
  • Agente Pessoal OpenClaw: Bot autônomo com arquitetura 4-way free-tier fallback para garantias de alta disponibilidade com custo zero.
  • Gaming: Servidor de Minecraft dedicado e otimizado para jogar com amigos.
Docker • OpenMediaVault • Tailscale • OpenClaw
